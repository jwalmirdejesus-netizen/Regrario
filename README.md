Regrário não é mais uma linguagem pra você decorar sintaxe. É um circuito que você vê funcionando.

A ideia nasceu de uma frustração simples: programar é legal, mas começar é doloroso. Muita regra, muito medo de errar, zero dopamina. Então eu criei uma linguagem que funciona como o seu cérebro funciona quando está inspirado.

### O que é, na prática?

Variáveis viram nós. Regras viram fios. Você conecta.

- **Variáveis simples, listas e objetos** são nós no circuito
- **Regras combinam condições** com E / OU / NÃO
- **Repete com ENQUANTO** ou percorre tudo com PARA CADA
- **Cria funções reutilizáveis** com parâmetros e retorno — inclusive recursivas, com proteção contra loop infinito

É visual. É ao vivo. Você clica e vê a corrente passando. Se acende verde, funcionou. Se fica vermelho, não passou. Sem console obscuro.

**0 campos obrigatórios** - você já vê o resultado antes de terminar.
